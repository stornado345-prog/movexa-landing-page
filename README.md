# 🎬 MOVEXA — Smart Cinema Self-Service

A modern landing page concept for **MOVEXA**, a smart cinema self-service kiosk designed to simplify the movie ticket booking experience.

MOVEXA is a portfolio project that presents a concept for a touchscreen cinema kiosk where customers can select movies, schedules, studios, seats, make digital payments, and receive their tickets.

## 📌 About MOVEXA

MOVEXA is a **Smart Cinema Self-Service Kiosk** concept designed for modern cinema environments.

The goal is to reduce traditional ticket-counter queues and provide customers with a faster and more convenient ticketing experience through a touchscreen kiosk.

### Customer Flow

```text id="t3pkqw"
Choose Movie
      ↓
Select Schedule
      ↓
Select Studio
      ↓
Select Seat
      ↓
Make Payment
      ↓
Generate Ticket Code
      ↓
Print Ticket
```

## 🏗️ MOVEXA System Architecture

The planned architecture can be represented as:

```text id="h9k7ax"
                MOVEXA SYSTEM
                     │
          ┌──────────┴──────────┐
          │                     │
     Android Kiosk          Admin Panel
          │                     │
    Kotlin + Compose        Laravel Filament
          │                     │
          └──────────┬──────────┘
                     │
                Laravel API
                     │
                  MySQL
                     │
          ┌──────────┴──────────┐
          │                     │
      Payment               Ticketing
    QRIS / VA             & Printing
```

The Android kiosk communicates with the Laravel backend through REST APIs.

The cinema administrator can manage operational data through the Laravel Filament admin panel.

Combine Android kiosk technology, Laravel backend, digital payment, and ticket printing into a modern cinema experience.
